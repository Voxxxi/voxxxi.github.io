# Очередь ИИ VOXi

Пользователь разрешил бесплатный Workers AI и передачу вопросов оператору Cloudflare 20.10.2026. Форма ключа проверена по видимым DOM полям: Account / Workers AI / Read и Account / Workers AI / Edit, ресурс только аккаунт владельца. После одного отказа авторевью по неуточнённым полям значения прочитаны из DOM, повтор разрешён. Значения секрета не сохранять в файлы.

План: Qwen3-30B-A3B-fp8 (входит в free allocation, не Kimi из примера панели). Проверить фактический Workers Free тариф до запуска. Ограничить ввод, вывод и суммарные дневные вызовы сервером (включая одновременно идущие); при исчерпании отвечать справочными шаблонами/контактами без платного резерва. Оператор отвечает автоматически RU/KK по языку посетителя, знания из VOXI_OPERATOR_KNOWLEDGE.md. Отдельная личная вкладка чата; общие ответы по явному обращению @VOXi с пометкой ИИ, без публикации личных сведений.

Мониторинг: серверная задача каждые5мин выполняет технические проверки HTTPS/страницы/манифест/база; агрегированный результат владельцу. ИИ объясняет только новые неполадки, не вызывается на каждый успешный опрос. Без автоматических изменений кода/блокировок/удалений и без гарантии проверки абсолютно всего. Настройка cron должна быть реально подтверждена, не обещать фон до этого.
