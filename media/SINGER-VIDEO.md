# VOXi studio portrait

The silent singer clip was generated locally from the existing VOXi background image using Wan 2.2 TI2V 5B in ComfyUI, on the owner's RTX 4060 Ti. No hosted generation subscription or runtime API is required.

`singer-loop.mp4`: H.264, 800 x 450, 16 fps, 30.1875 seconds, no audio stream. The original generated segment is 81 frames; a 12-frame crossfade creates a 69-frame repeating cycle. Seven cycles form the exported clip. `singer-poster.jpg` is its first frame.

The MP4 and poster are served by this website. Keep a local backup with the owner. Generation software/model are not needed for playback.
