Проверка установки

Сейчас открыт Samsung Internet

Этот браузер сообщил об ошибке установки. Продолжим проверку в Google Chrome.

Открыть проверку в Google Chrome

Если Chrome ещё не установлен, откроется его страница в Google Play. После установки Chrome откройте в нём voxxxi.github.io/install-check.html.

Эта страница проверяет, загружаются ли настройки и иконки приложения с вашего телефона. Она не обращается к личному кабинету.

Готовим проверку…

    Установка через браузер

    Кнопка станет доступна, если браузер предоставит окно установки. Установку нужно подтвердить в системном окне.

    Результат для отправки в чат

    Если после подтверждения появляется «Не удалось установить приложение», приложите скриншот этого сообщения. Сайт не получает подробную причину системного сбоя.
